# Sales Data Analysis & Dashboard using Excel

## 📌 Project Overview
This project focuses on analyzing monthly sales data using Microsoft Excel.
The objective is to transform raw sales data into meaningful insights through
data cleaning, reports, KPIs, charts, slicers, and an interactive dashboard.

---

## 🎯 Project Objectives
- Analyze monthly sales performance
- Identify top-selling products and categories
- Track total sales and revenue trends
- Create KPIs for quick business insights
- Build an interactive sales dashboard

---

## 📂 Dataset Description
The dataset contains sales transaction data, including:
- Order Date
- Product Name
- Category
- Sales Amount
- Quantity
- Region / Location

Each row represents a single sales transaction.

---

## 🧹 Data Cleaning Process
The following steps were performed before analysis:
- Verified raw sales data structure
- Checked for missing or incorrect values
- Ensured numeric formatting for sales and quantity
- Prepared clean data for pivot-based reporting

---

## 📊 Reports Created (Pivot Tables)
The following analytical reports were created:
- Top Sales of the Month
- Category-wise Sales Summary
- Product-wise Sales Analysis
- Region-wise Sales Distribution

These reports help understand sales performance across different dimensions.

---

## 📈 KPIs (Key Performance Indicators)
Key KPIs included in the project:
- Total Sales
- Total Quantity Sold
- Average Sales per Order
- Highest Sales Value

---

## 📉 Dashboard Features
The dashboard includes:
- Interactive charts based on pivot tables
- Slicers for Category, Product, and Region
- Monthly sales performance visualization
- Clean and user-friendly layout

---

## 🛠 Tools & Techniques Used
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Excel Functions (SUM, AVERAGE, MAX)
- Slicers & Filters
- Dashboard Design Techniques

---

## 🧠 What I Learned
- Converting raw sales data into reports
- Using pivot tables for business analysis
- Creating KPIs for performance tracking
- Designing interactive Excel dashboards

---

## 📌 Conclusion
This project demonstrates my ability to analyze sales data using Excel from raw data to dashboard.
It reflects practical Excel and business analysis skills suitable for entry-level analyst roles.

# Employee Data Analysis Project (Excel)

## 📌 Project Description
This project focuses on analyzing employee data using Microsoft Excel.
The goal of the project is to clean raw employee data, create analytical reports,
generate KPIs, and design an interactive dashboard for better decision-making.

---

## 📂 Dataset Information
The dataset contains employee-level information such as:
- Employee ID
- Employee Name
- Department
- Designation
- Gender
- Date of Joining
- Salary
- Location

---

## 🧹 Data Cleaning Steps
- Removed duplicate employee records
- Handled missing values
- Standardized date and salary formats
- Prepared clean data for analysis

---

## 📊 Reports Created (Using Pivot Tables)
- Department-wise Employee Count
- Department-wise Average Salary
- Gender-wise Employee Distribution
- Top 5 Highest Paid Employees

---

## 📈 KPIs (Key Performance Indicators)
- Total Number of Employees
- Average Salary
- Highest Salary
- Lowest Salary

---

## 📉 Dashboard Features
- Interactive charts created from pivot tables
- Slicers for Department, Gender, and Location
- Dynamic filtering of data
- Clean and professional dashboard layout

---

## 🛠 Tools & Techniques Used
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Excel Functions (COUNT, AVERAGE, MAX, MIN)
- Slicers and Filters

---

## 🧠 Key Learnings
- Practical experience with Excel data analysis
- Hands-on dashboard creation
- Understanding of business-level reporting
- Data cleaning and structuring techniques

---

## 📌 Conclusion
This project demonstrates my ability to perform end-to-end data analysis using Excel.
It reflects real-world analytical skills suitable for entry-level data analyst roles.

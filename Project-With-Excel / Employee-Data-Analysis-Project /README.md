# Employee Data Analysis Project using Excel

## 📌 Project Overview
This project demonstrates an end-to-end **Employee Data Analysis** workflow using Microsoft Excel.
The project starts with raw employee data and progresses through data cleaning, report generation,
KPI creation, and the development of an interactive dashboard.

This project is part of my Excel learning and practice portfolio.

---

## 🎯 Project Objectives
- Understand and organize raw employee data
- Perform data cleaning for accurate analysis
- Create analytical reports using pivot tables
- Generate KPIs for quick business insights
- Build an interactive Excel dashboard using charts and slicers

---

## 📂 Dataset Description
The dataset contains employee-level information, including:
- Employee ID
- Employee Name
- Department
- Designation
- Gender
- Date of Joining
- Salary
- Location

Each row represents one employee record.

---

## 🧹 Data Cleaning Process
The following data cleaning steps were performed:
- Removed duplicate employee records
- Handled missing or blank values
- Standardized date formats
- Converted salary values to numeric format
- Prepared a clean dataset for reporting and analysis

---

## 📊 Reports Created (Pivot Tables)
The following reports were generated using Excel Pivot Tables:
- Department-wise Employee Count
- Department-wise Average Salary
- Gender-wise Employee Distribution
- Top 5 Highest Paid Employees

These reports help understand workforce distribution and salary trends.

---

## 📈 Key Performance Indicators (KPIs)
The project includes the following KPIs:
- Total Number of Employees
- Average Salary
- Highest Salary
- Lowest Salary

KPIs provide a quick summary of the overall employee data.

---

## 📉 Dashboard Features
An interactive dashboard was created with:
- Pivot-based charts
- Department, Gender, and Location slicers
- Dynamic filtering of reports
- Clean and easy-to-understand layout

The dashboard allows users to explore employee data interactively.

---

## 🛠 Tools & Techniques Used
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Excel Functions (COUNT, AVERAGE, MAX, MIN)
- Slicers and Filters
- Basic data cleaning techniques

---

## 🧠 Key Learnings
- Practical experience in Excel data analysis
- Creating meaningful reports from raw data
- Designing KPI metrics
- Building interactive dashboards
- Understanding business-focused reporting

---

## 📌 Conclusion
This project showcases my ability to analyze employee data using Excel from raw data to dashboard.
It reflects real-world Excel skills suitable for entry-level data analyst and MIS roles.
